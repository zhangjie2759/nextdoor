《下一间》网页版本 - 图片图层 / 角色槽位 / 无限门过渡版

上传 Netlify：
1. 直接把整个 next_room_infinite_transition 文件夹拖到 Netlify
2. 或上传 next_room_web_infinite_transition.zip

本版更新：
1. 安全房间进入下一间时，人类角色会先慢慢淡出，不再硬切消失。
2. 房间深处的小门会直接放大，最终变成外面同尺寸的完整门，形成“无限空间 / 下一间”的连续感。
3. 安全房间转场不再用黑场硬切；切房间时画面已经变成新门，过渡更自然。
4. 保留已有逻辑：简单/困难、门自动吸附、只出现已放入的鬼/人物图片、临时鬼/人物不再出现。

角色图片命名：
assets/ghosts/一号鬼.png ... assets/ghosts/十二号鬼.png
assets/people/一号人物.png ... assets/people/十二号人物.png

注意：
只会随机出现已经放入文件夹、并且能成功加载的角色图片。


本版更新：内部门过渡改为整体门框矩形放大/平移，最终会和外层门框与外层门洞重叠，避免位置漂移。
